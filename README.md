# LangChain

Hands-on practice code from my Generative AI with LangChain learning journey. I followed the **CampusX** GenAI with LangChain course and implemented each concept in this repository.

## What's Covered

- **LLMs & Chat Models**: working with LLMs and chat models via LangChain
- **Embedding Models**: generating text embeddings
- **Prompts**: prompt templates and dynamic prompting
- **Structured Output & Output Parsers**: getting reliable, typed responses from models
- **Chains**: sequential, parallel and conditional chains
- **Runnables**: LangChain Expression Language (LCEL) building blocks
- **Document Loaders & Text Splitters**: ingesting and chunking documents
- **Vector Stores & Retrievers**: semantic search and retrieval
- **Tools, Tool Calling & Agents**: building agents with custom tools and DuckDuckGo search

## Tech Stack

Python, LangChain, OpenAI API

## Setup

1. Clone the repo
   ```bash
   git clone https://github.com/Bhumi701/LangChain.git
   cd LangChain
   ```
2. Create and activate a virtual environment, then install dependencies
   ```bash
   python -m venv venv
   venv\Scripts\activate
   pip install -r requirements.txt
   ```
3. Create a `.env` file in the root folder
